Desafio Xlow - Vitrine de Produtos

Sobre o Projeto

Este projeto é um desafio técnico para uma vaga de trabalho.
O objetivo é desenvolver uma página de vitrine de produtos, consumindo os dados de
uma API externa e implementando funcionalidades dinâmicas de exibição.

Funcionalidades

- Exibir um contador com o número total de produtos retornados pela API.

- Implementar um botão de alteração da quantidade de produtos por linha:

  No mobile: alternar entre 1 e 2 produtos por linha.

  No desktop: alternar entre 4 e 5 produtos por linha.

- Exibir uma vitrine de produtos com as seguintes informações:

  Imagem principal do produto.

  Nome do produto.

  Imagens das variações do produto (miniaturas).

  Preço, com destaque visual para o preço com desconto (se aplicável).

  Botão de compra (sem necessidade de ação ao clicar).

  Interatividade: ao clicar em uma miniatura de variação, a imagem principal do produto deve ser trocada por ela.
